So installierst du sie

How to install

Die Mac-Version ist von Apple geprüft und startet ohne Warnung. Unter Windows zeigt der Computer beim ersten Start noch einen Hinweis – so kommst du vorbei:

The Mac version is notarized by Apple and opens without a warning. On Windows you'll still see a notice on first launch – here's how to get past it:

Mac

  1. ZIP herunterladen und doppelklicken.
  2. Desktop Buddies in den Ordner Programme ziehen und öffnen.
  3. Bei der Frage „Aus dem Internet geladen …“ auf Öffnen klicken.
  1. Download the ZIP and double-click it.
  2. Drag Desktop Buddies into Applications and open it.
  3. When asked about an app “downloaded from the Internet”, click Open.

Windows

  1. ZIP herunterladen, Rechtsklick → Alle extrahieren.
  2. Im Ordner Desktop Buddies.exe doppelklicken.
  3. Bei „Der Computer wurde durch Windows geschützt“ auf Weitere Informationen → Trotzdem ausführen.
  4. Das Mochi-Symbol erscheint unten rechts neben der Uhr – ein Klick öffnet das Menü.
  1. Download the ZIP, right-click → Extract All.
  2. Double-click Desktop Buddies.exe in the folder.
  3. On “Windows protected your PC”, click More info → Run anyway.
  4. The Mochi icon appears next to the clock – click it for the menu.
